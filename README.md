# House Price Prediction

## Project Overview

This project predicts house prices using Machine Learning and Linear Regression.

The project uses house-related features to train a Linear Regression model and predict house prices.

## Dataset

The dataset contains the following features:

- Area
- Bedrooms
- Bathrooms
- Age
- Location Score
- Price

The `price` column is the target variable.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Jupyter Notebook

## Project Workflow

1. Load the dataset
2. Explore and understand the data
3. Select features and target variable
4. Split the data into training and testing sets
5. Train the Linear Regression model
6. Predict house prices
7. Evaluate the model
8. Visualize actual and predicted prices

## Machine Learning Model

Linear Regression is used to predict house prices based on the selected features.

## Project Files

- `houseprice.ipynb` – Jupyter Notebook containing the complete machine learning workflow.
- `house_prices.csv` – Dataset used for the project.
- `README.md` – Project documentation.

## How to Run

1. Download or clone this repository.
2. Open `houseprice.ipynb` using Jupyter Notebook.
3. Make sure `house_prices.csv` is in the same folder.
4. Run the notebook cells from top to bottom.

## Conclusion

This project demonstrates how Linear Regression can be used for house price prediction and introduces the basic workflow of a machine learning regression project.
